# Implementation summary: deliverable ID

## Result
Explain what was produced and where it lives.

## Task status
List each task ID and whether it is complete, partial, or blocked.

## Verification performed
For each check, record the command or inspection, observed result, and relevant AC IDs. Record checks not performed as not_run and give the reason.

## Assumptions and deviations
Record assumptions, differences from the plan, and their reasons. Identify plan revisions if any.

## Remaining work
State blockers or follow-up work. Write None if all planned work is complete.
