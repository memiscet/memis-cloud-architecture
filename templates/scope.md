# Scope: project name

## Problem and people
Who needs help? What is difficult today? Cite existing information where available.

## Intended result
What should be different when this project succeeds?

## Success measures
How will someone observe or measure that difference? Mark proposed targets as proposed.

## Included
List the capabilities or outcomes this project will deliver.

## Excluded
List nearby requests that this project will not take on.

## Constraints
Record real limits on time, money, tools, access, or ways of working.

## Assumptions
Separate working assumptions from confirmed facts.

## Open questions
Name undecided issues and who can resolve them. Write None if there are none.
