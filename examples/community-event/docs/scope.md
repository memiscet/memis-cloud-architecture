# Scope: fictional community welcome guide

## Problem and people
Guests need a short reference for arrival and help. A room assignment might change after a guide is printed.

## Intended result
Produce one plain-text guide for a fictional event at Riverside Community Hall. It names arrival instructions and a reliable fallback when the guest's information is missing or outdated.

## Success measures
The sample document contains an arrival section with the venue and welcome desk, a missing-details section directing guests to the welcome desk, and a room-change section doing the same. All essential instructions appear in the document without relying on a link.

## Included
Arrival instructions, missing-information guidance, room-change guidance, and a concise help section.

## Excluded
Registration, ticketing, real venue confirmation, event scheduling, layout production, physical print checks, and a study with actual guests.

## Constraints
Plain text in a Markdown file; no phone or internet required to read the essential instructions. All event details are fictional.

## Assumptions
A welcome desk is available at the fictional venue's main entrance.

## Open questions
None for this sample. A real event would require coordinator confirmation.
