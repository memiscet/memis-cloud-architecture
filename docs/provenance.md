# Provenance and reuse

This repository adapts [Reusable Delivery Framework](https://github.com/memiscet/reusable-delivery-framework) at commit `6cbbcb5205c28ada8e8e956bd593fe73eb12d0c6`. The seven canonical skills, schemas, templates, original examples, evaluation guidance, and base Python tests/tools are reused under that project's MIT license. Copyright and license notices are retained.

The memis.cloud architecture, Terraform, new integration tools/tests, Copilot wrappers, project artifacts, and new documentation were created for this request. Source application code, credentials, dependency folders, Git history, and Terraform state were not copied. The source framework's older extraction analysis remains in docs/framework-analysis.md as historical background; docs/framework-adaptation.md describes this project.

Architecture references are linked beside claims and indexed in docs/sources.md. They were consulted on 2026-10-28. All example account IDs and hosted-zone placeholders are illustrative. The user-provided domain name and memiscet repository owner are intentionally public project identifiers.

No real AWS deployment, production test, or interactive Copilot session is implied by the repository or local checks.
