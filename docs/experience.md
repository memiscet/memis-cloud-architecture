# Experience: using the workspace

A contributor reads the simple guide, opens the repository root in VS Code, chooses Copilot's agent mode, and invokes a stage prompt with an explicit project. For a delivery stage they also supply the exact deliverable ID. They inspect saved artifacts, run checks, and review evidence before continuing.

If automatic skill discovery fails, the contributor asks Copilot to read the exact canonical SKILL.md path. If a generated copy differs, synchronization checks explain how to regenerate it. If a source promise or plan changes, the normal validator reports the stale handoff. The tutorial explains that creating a repository does not create AWS resources.

Documentation uses text tables as well as diagrams and explains unfamiliar terms. There is no claimed interactive Copilot, accessibility, or user-study result. Static validation and manual steps are clearly separated.
