# Glossary

| Term | Simple meaning |
|---|---|
| VPC | A private network boundary in AWS |
| CIDR | A compact way to describe an address range, such as /24 |
| Subnet | One smaller address range in one Availability Zone |
| Availability Zone | An independently operated location within an AWS region |
| Route table | Rules choosing where network traffic goes next |
| Internet Gateway | VPC connection used for public internet routing |
| NAT Gateway | Outbound address translation for connections initiated by private resources |
| CDN / CloudFront | Public edge service that receives requests near users and can cache safe content |
| VPC origin | CloudFront's private connection to a supported resource inside a VPC |
| ALB | Application Load Balancer; forwards HTTP/HTTPS requests to targets |
| Nginx | Web server and reverse proxy |
| Runtime | Software executing the application's business logic |
| RDS | AWS-managed relational database service |
| S3 | Object storage; buckets contain objects identified by keys |
| Gateway endpoint | Route-table integration for reaching a supported AWS service |
| Security group | Stateful network connection rules attached to resources |
| IAM role | Temporary AWS permissions assumed by a service or workload |
| ACM / TLS | Managed certificates / encrypted transport and server identity |
| Terraform | Configuration tool describing and managing infrastructure |
| Mock | Simulated provider result used for local tests |
| Artifact | A saved output such as a scope, plan, configuration, or review |
| Acceptance criterion | A specific promise about an observable result |
| Skill | Reusable instructions for one workflow stage |
